# Ciclo 4: alinear la documentación del frontend

## Objetivo

Eliminar las instrucciones de frontend obsoletas y describir el stack que implementa el repositorio: React 19, TypeScript, Vite y Tailwind CSS.

## Criterios de aceptación

- El README principal describe el stack, las rutas actuales de React Router y los comandos/configuración de desarrollo existentes.
- El README del frontend documenta los scripts definidos en `frontend/package.json` y el puerto/API configurados en Vite y Docker Compose.
- El prompt de trabajo indica que ambos README deben mantenerse coherentes con la implementación.
- No se modifica código de producto.

## Plan

1. Actualizar las secciones de frontend del README principal.
2. Sustituir las instrucciones generadas del README del frontend por instrucciones verificadas contra los archivos de configuración.
3. Actualizar `GOAL_PROMPT.md` y registrar el ciclo en `AGENT_CHANGELOG.md`.
4. Revisar las diferencias y buscar referencias al framework anterior que hayan quedado en la documentación.
